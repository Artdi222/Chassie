# Chassie application icon

Asset: `ui/public/chassie-icon.png`. Generated with the built-in image generation
tool, then copied unchanged into the project. The previous portrait remains at
`ui/public/image.png`.

Used by the desktop launcher, Qt application windows, the studio tray, and the
browser favicon. Relaunch an existing desktop process to load the new window/tray
icon.

## Generation prompt

Use case: logo-brand. Asset type: finished desktop application icon for Chassie, a warm personal AI chat companion. Create exactly one square 1:1 icon, 1024x1024. Design a bold, beautifully simple white speech-bubble symbol whose open inner negative space subtly forms a capital C, centered inside a flat muted lavender-purple (#7055b5) rounded-square tile. One cohesive geometric mark, soft rounded ends, balanced proportions, friendly and calm. Large silhouette, generous but not excessive safe margins, legible at 24x24. Flat vector-like solid shapes with crisp antialiased edges, only white and lavender purple. The tile occupies about 90 percent of the square canvas; genuinely transparent background outside its rounded corners. No photograph, no portrait, no character illustration, no lettering or wordmark, no sparkles, no extra icons, no gradients, no lighting effects, no shadows, no 3D, no mockup, no presentation board. Output a single production-ready app icon.
