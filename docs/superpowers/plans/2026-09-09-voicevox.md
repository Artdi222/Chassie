User-approved scope: Indonesian/English input, Japanese Mochiko-san speech, English chat/subtitles, local web and desktop. This replaces the earlier deferred-TTS decision.

1. Install pinned official VOICEVOX Core CPU runtime, dictionary and only the VVM containing Mochiko-san. Load one VVM on demand in an owned subprocess; keep it warm, bound work and terminate it on cancellation/timeout/shutdown. CPU with two threads preserves GPU memory for the avatar.
2. Request one short Japanese/English sentence pair plus a supported emotion per JSON line from Hermes. Validate completed pairs before speech/display; never expose protocol JSON or speak English with the Japanese voice. Keep existing English Edge mode compatible.
3. Route each Japanese sentence to speech and its English partner to chat/subtitles and displayed history. Preserve completed-sentence interruption semantics, bounded prefetch, multilingual STT and privacy controls.
4. Show English voice/language information and required voice attribution in shared settings. Document setup and provide a real WAV sample.
5. Test split and malformed bilingual streams, synthesis/errors/cancellation, UI history reconnection, existing conversation regressions, and actual local synthesis. Measure local synthesis only; do not claim unmeasured end-to-end response speed.
